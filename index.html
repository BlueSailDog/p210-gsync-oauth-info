P210 Sync Test

This is the public information page for a personal Google OAuth application used by one account owner to connect Obsidian's GSync plugin to the owner's Google Drive.

The connection synchronizes Markdown test notes between the owner's Windows computer, iPhone, and the Google Drive folder named P210-Sync-Test. This page does not offer a public sign-up or a hosted syncing service.

GSync requests permission to view and manage all files in the owner's Google Drive. That Google permission is broader than the folder selected in the plugin; GSync's folder setting determines which files it actually synchronizes. Please review the plugin's source and the consent screen before granting access.
