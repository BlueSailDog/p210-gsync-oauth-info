Privacy policy

Last updated: 16 November 2026

Purpose and access

P210 Sync Test is a personal OAuth configuration for the account owner's use of the open-source GSync plugin in Obsidian. GSync requests the full Google Drive permission (https://www.googleapis.com/auth/drive) to find and synchronize existing files. This permission can technically access all files in the authorized Drive account. The plugin is configured to synchronize the owner's selected folder, P210-Sync-Test.

Data handling

The GSync plugin transfers the selected vault files directly between the owner's device and Google Drive. The client ID, client secret, and refresh token are stored in the plugin's device-local settings file. This informational site does not receive Drive file contents or OAuth credentials.

During sign-in, the plugin's default static callback page on dg0988.github.io passes a one-time authorization code back to Obsidian. The callback page is maintained by the GSync author; consult the plugin's documentation and source for its behavior. This site is hosted by GitHub Pages, whose handling of standard website access data is governed by GitHub's own policies.

Sharing and retention

The account owner does not sell Google user data. Files remain in the owner's Google Drive and on the owner's devices until the owner removes them. Local OAuth credentials remain on each configured device until the owner removes the plugin settings. Access can be revoked from Google Account permissions.

Contact

For questions about this personal integration, contact the application owner through the support email shown on the Google OAuth consent screen.
